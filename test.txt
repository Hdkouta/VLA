Ubuntu 向けに置き換えた手順です。

1. **掴んでいるプロセスの解放**(Python や Viewer の終了):
   ```bash
   pkill -f python; pkill -f OrbbecViewer
   # 掴んでいるプロセスの特定
   lsof /dev/bus/usb/*/* 2>/dev/null | grep -i python
   ```
2. **USB 認識の確認**(Orbbec のベンダー ID は 2bc5):
   ```bash
   lsusb | grep -i 2bc5
   lsusb -t   # USB3(5000M)か USB2(480M)かを確認
   ```
3. **権限(udev ルール)**: Ubuntu で open に失敗する最大の原因です。
   ```bash
   # SDK 付属のスクリプトを使う場合(pyorbbecsdk のリポジトリ内)
   sudo bash ./scripts/install_udev_rules.sh
   # 手動の場合
   echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="2bc5", MODE="0666", GROUP="plugdev"' | sudo tee /etc/udev/rules.d/99-obsensor-libusb.rules
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```
   実行後に USB を抜き差ししてください。
4. **ユーザーグループ**:
   ```bash
   sudo usermod -aG plugdev $USER   # 反映にはログアウトと再ログインが必要
   ```
5. **カーネルログ**(接続時のエラーを確認):
   ```bash
   sudo dmesg | grep -iE "usb|orbbec|uvc" | tail -30
   ```
6. **SDK のバージョン**:
   ```bash
   pip show pyorbbecsdk
   ```

2台とも open に失敗している場合は、手順3の udev ルールが未設定の可能性が高いです。`lsusb` の出力と `dmesg` の結果を貼ってください。
