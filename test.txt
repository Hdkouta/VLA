0番も1番も情報取得と open に失敗しているので、片方のカメラの問題ではありません。SDK が USB を開けない状態で、Python から見えているのに触れない、という症状です。次の順で確認してください。

1. **掴んでいるプロセスの解放**:
   ```powershell
   Get-Process python, OrbbecViewer, pythonw -ErrorAction SilentlyContinue | Stop-Process -Force
   ```
   VS Code の Python デバッグセッションや、Jupyter のカーネルが残っていることもあります。VS Code のターミナルとデバッグを全て閉じてください。
2. **Orbbec Viewer で2台とも映るか確認**:
   - 映らない場合は、ドライバかファームウェアの問題です。Viewer を入れ直すとドライバも入ります。
   - 映る場合は、Viewer を閉じてから Python を再実行してください。
3. **ドライバの確認**:
   ```powershell
   Get-PnpDevice -PresentOnly | Where-Object { $_.FriendlyName -match "Orbbec|Gemini" } | Format-Table FriendlyName, Status, Class
   ```
   `Status` が `Error` の場合や、`Class` が `Unknown` の場合はドライバ未適用です。
4. **ポートの変更**: 本体の背面 USB3 ポートに直挿しします。ハブや前面ポートは避けてください。
5. **SDK との整合**: `pip show pyorbbecsdk` でバージョンを確認します。Gemini 335 系は新しい `pyorbbecsdk`(v2 系)が必要です。古い版では open に失敗することがあります。

カメラの型番(Gemini 2 / 335 / 335L など)と、手順3の出力、`pip show pyorbbecsdk` の結果を教えてください。それで原因を絞り込みます。
