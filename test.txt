このリポジトリには、カメラ用の環境変数や設定コマンドの記載はありません。`pyorbbecsdk` を `pip` で入れた場合は、通常は環境変数は不要です。

## 通常（pipで入れた場合）

環境変数は不要です。代わりに次の2つを確認します。

```bash
# カメラにアクセスできるよう video グループに入れる（再ログインが必要）
sudo usermod -aG video $USER

# Orbbec用のudevルールを入れる（OrbbecSDKに同梱の rules ファイルを使う）
sudo cp 99-obsensor-libusb.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger
```

`99-obsensor-libusb.rules` は、OrbbecSDK または `pyorbbecsdk` のリポジトリ（`scripts/` 内）にあります。

## SDKをソースからビルドして使う場合

ビルドした `pyorbbecsdk` を、Pythonが見つけられるように指定します。パスは自分の配置場所に合わせて変えてください。

```bash
export PYTHONPATH=$PYTHONPATH:~/pyorbbecsdk/install/lib/
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:~/pyorbbecsdk/install/lib/
```

毎回入力しないよう、`~/.bashrc` に追記しても構いません。

## 確認

```bash
python3 -c "import pyorbbecsdk; print(pyorbbecsdk.__file__)"
lsusb | grep -i orbbec
```

インポートに失敗する場合は `PYTHONPATH`、デバイスが見えない場合は udev と `video` グループが原因です。

どの方法で `pyorbbecsdk` を入れたかを教えてもらえれば、それに合わせたコマンドに絞ります。
